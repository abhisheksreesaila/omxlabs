omxcode · the framework

Write it once. Native everywhere.

Two functions, view() and update(). Linux, the web, Android and Mac draw it with their own widgets. iPhone builds.

The GPU code sits in the same file. And every app is an MCP server.

omxlabs.tech/omxcode ›

struct Main(App):
    var name: String
    var clicks: Int

    def update(mut self, event: Event):
        if event.message == GREET:
            self.clicks += 1

    def view(self) -> View:
        return VStack(
            Text("Hello, " + self.name, style=TITLE),
            Button("Greet", on_tap=GREET, style=PROMINENT),
        )
