How you'd write one

An app is a struct: state, update, view.

examples/hello/app.mojo · the whole app; title() and blank lines left out
from mojoui import App, Event, View, VStack, Text, Button, TITLE, CAPTION, PROMINENT
comptime GREET = 1          # a message is just a number
struct Main(App):
    var name: String
    var clicks: Int
    def __init__(out self):
        self.name = "Ada"
        self.clicks = 0

    def update(mut self, event: Event):
        if event.message == GREET:
            self.clicks += 1

    def view(self) -> View:
        var greeting = "Tap Greet" if self.clicks == 0 else "Hello, " + self.name + "! (click " + String(self.clicks) + ")"
        return VStack(
            Text(greeting, style=TITLE),
            Button("Greet", on_tap=GREET, style=PROMINENT),
            Text("Every line of this app is Mojo.", style=CAPTION),
            spacing=20,
        )

The GPU, in the same file

A Mojo function becomes a GPU kernel.

examples/gpu/app.mojo · real code, trimmed
def mandelbrot(x: Int, y: Int, w: Int, h: Int, p: Params) -> UInt32:
    """Colour of one pixel. p = (scale, centre x, centre y, max iterations)."""
    var cx = p[1] + (Float32(x) - Float32(w) / 2) * p[0] / Float32(h)
    var cy = p[2] + (Float32(y) - Float32(h) / 2) * p[0] / Float32(h)
    var zx = Float32(0)
    var zy = Float32(0)
    var i = 0
    var limit = Int(p[3])
    while i < limit and zx * zx + zy * zy < 4.0:
        var t = zx * zx - zy * zy + cx
        zy = 2.0 * zx * zy + cy
        zx = t
        i += 1          # … colour from i, returned as one pixel
    def render(mut self, check: Bool):
        var gpu = self.gpu.render[mandelbrot](WIDTH, HEIGHT, self.params())   # one GPU thread per pixel
        self.pixels = gpu.pixels.copy()
        if check:   # the same function on the CPU: the pixels must match
            var cpu = render_on_cpu[mandelbrot](WIDTH, HEIGHT, self.params())
    def view(self) -> View:
        return VStack(
            Image(self.pixels, WIDTH, HEIGHT),
            HStack(Text("Zoom"), Slider(self.zoom, on_change=ZOOM), spacing=12),
            Button("Run on GPU", on_tap=RUN, style=PROMINENT),
        )

mojoui/gpu.mojo launches it as _pixels_kernel[f] in 16 × 16 blocks · no CUDA, no shader language

Give it to an agent

Every app is an MCP server.

$ scripts/agent.sh hello
claude mcp add hello -- pixi run python …/agent.py …/build/hello/web
→ screen
← "Tap Greet" · Button "Greet" → greet
→ greet
← Did greet. Now: Hello, Ada! (click 1)

No per-app work. A button's tag, or its title, names its tool. Tapping it and calling it are the same.

The screen is the permission model. A disabled button is no tool. A dialog's buttons exist only while it's open.

It answers in words. Each call returns what changed, not a screenshot to compare.

The honest edges

What it can't do yet.

🌱

Mojo is young.

Version 1.1, a small ecosystem, no Windows release. Flutter and React Native are far ahead on maturity.

📱

iPhone only builds.

It compiles and signs, with two hand-written runtime functions. It hasn't run on a phone.

🤖

Android is partial.

19 components run on the emulator; the newer ones are still to come.

🍎

The Mac is on loan.

omxplorer runs on GitHub's Macs. The matrix still counts Mac components as “builds”.

🎮

NVIDIA first.

The GPU path is NVIDIA. Apple and phones run the same functions on the CPU.

🦀

Not always fastest.

Native Rust wins at 1M particles, cold start and memory.
