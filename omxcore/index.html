Five things in one small engine.

📂

Your files stay yours.

No import, no new format. Ask a CSV or a Parquet file directly. Files bigger than memory stream through a row group at a time.

⚡

Your hardware, all of it.

CPU or GPU, chosen per query, with the reason. AUTO prices both, copies included, on your machine.

🤖

Answers an agent can trust.

JSON out, exact decimals, and errors with a line, a column and a “did you mean” hint.

🔥

Mojo, top to bottom.

Parser, planner, CPU and GPU kernels in one language. It links into apps like omxplorer.

🧩

Real SQL.

Joins, CTEs, subqueries, windows, QUALIFY. 21 of 22 TPC-H queries through mx equal DuckDB.

2 Python · import omxcore
import omxcore as mx

lf = mx.scan_parquet("lineitem.parquet")
out = (lf
  .filter(mx.col("l_quantity") < 24)
  .groupby("l_returnflag")
  .agg(mx.col("l_extendedprice")
       .sum().alias("revenue"))
  .compute(device="auto"))
# nothing runs until compute()
