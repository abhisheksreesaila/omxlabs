## 💡 Why

Your own hardware is enough. omxlabs builds software in Mojo that runs serious data and AI work on the GPU you already own,
and that an AI agent can use as easily as you can.

## ✨ The suite

| | | |
|---|---|---|
| 💬 [**omxplorer**](https://omxlabs.tech/omxplorer/) | the flagship | ask your data in a sentence; every button is an agent tool |
| ⚡ [**omxcore**](https://omxlabs.tech/omxcore/) | powers it | SQL on your CPU and GPU, over the files you already have |
| 🧩 [**omxcode**](https://omxlabs.tech/omxcode/) | builds it | write an app once in Mojo, native on Linux, web, Android, Mac |
| 🔌 [**omxconsole**](https://omxlabs.tech/omxconsole/) | local AI | your GPU as a private, OpenAI-compatible model server |
| 🫧 [**omxqua**](https://omxlabs.tech/omxqua/) | the look | Google's surfaces, Apple's springs |

Each product has a cover page and a two-minute deck with the code. Read those; the READMEs stay short.

## 🛠️ This repo

The site itself: plain HTML, `assets/suite.css` (one cover layout, one accent per product), `assets/deck.css` + `deck.js`
(one reveal.js deck template), `assets/suite.js` (the suite list that draws every page's top bar and suite row).
`readmes/` holds the short README drafts for each product's repo. Preview: `python3 -m http.server` and open `/`.
