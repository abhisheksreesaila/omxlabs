omxcorethe engine

omxcore is why a million rows answer in under a millisecond.

SQL on your CPU and your GPU, over the files you already have. omxplorer's group-bys, medians and charts run as its GPU kernels, linked in like SQLite.

3.15sall 22 TPC-H queries at SF10 (DuckDB 5.08 s)

omxcodethe framework

omxcode is why omxplorer is one app on every screen.

Write an app once in Mojo, with its GPU code in the same file. Linux, the web, Android and Mac draw it with their own widgets, and every app is an MCP server an agent can drive.
