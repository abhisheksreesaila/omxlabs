Five things it does on purpose.

🧱

Solid, not glass.

Opaque tonal surfaces and one soft shadow scale, from Google. Only the nav pill is frosted; every card, menu and dialog stays solid and readable.

🌀

Springs with weight.

Every tap squashes and springs back, from Apple. The more often a thing happens, the less it moves: panels settle, menus ease, live data doesn't move.

🎨

Families and skins.

Dev, travel, kids and money. One root class repaints everything, and every pair clears 4.5:1.

🤖

Agents read it.

A skill and a Claude Code plugin. Ask for “a trip planner in omxqua” and it uses the real parts.

📦

Three files, no build.

tokens.css, components.css, omxqua.js. Plain HTML, CSS and JS.
